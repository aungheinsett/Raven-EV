# Raven-EV

RAVEN EV is a React Native EV charging app built with Expo, Firebase, and TypeScript. It includes station discovery, live charging status, Firebase-backed user flow, and a payment experience for EV users.

## Getting started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

## Features

- EV charging station discovery
- Live charging status tracking
- Firebase authentication and Firestore integration
- Mobile-first UI for EV users
