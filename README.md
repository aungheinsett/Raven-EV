# Raven EV

Raven EV is a modern React Native mobile app built with Expo that helps electric vehicle users discover charging stations, monitor live charging status, and manage a seamless EV charging experience.

## Overview

This project combines:
- a polished mobile UI for EV users,
- Firebase authentication and Firestore data handling,
- real-time charging status updates,
- and a simple onboarding and account flow.

## Features

- EV charging station discovery experience
- Live charging status screen
- User login and account creation
- Firebase-backed data storage
- Clean, modern mobile interface

## Tech Stack

- React Native
- Expo Router
- TypeScript
- Firebase
- Expo Vector Icons
- Linear Gradient and animations

## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/aungheinsett/Raven-EV.git
   ```

2. Install dependencies
   ```bash
   cd Raven-EV
   npm install
   ```

3. Start the app
   ```bash
   npx expo start
   ```

4. Run on device or emulator
   - Android: press `a`
   - iOS: press `i`
   - Web: press `w`

## Project Structure

- `app/` — screens and routing
- `components/` — reusable UI components
- `config/` — Firebase configuration
- `assets/` — images and app assets

## Notes

Make sure your Firebase configuration is set correctly in the project before running the app.
